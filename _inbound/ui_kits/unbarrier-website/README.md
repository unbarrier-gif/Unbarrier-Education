# Unbarrier Website UI Kit

A hi-fi recreation of the unbarrier.me marketing site.

## Components
- `Nav.jsx` — fixed translucent nav with scroll state
- `Hero.jsx` — full-height hero with illustration + "bring the joy" eyebrow
- `Services.jsx` — three-card services grid (audit / access / voice)
- `AboutBeliefs.jsx` — two-column about + "What I believe" list
- `Sections.jsx` — `StatStrip`, `Community`, `FinalCTA`, `Footer` (nav's fourth link now points at the blog instead of a hub)
- `Primitives.jsx` — `Eyebrow`, `SectionBar`, `Glow`, `Button`

Open `index.html` to see the composed landing page.

## Design notes
- Dark amethyst base, 70/20/10 colour ratio
- Section rhythm: thin gradient `SectionBar` between each section, accent rotates (aqua → orchid → yellow → spring green)
- Illustrations full-bleed on the right of feature sections
- One accent colour per section, never mixed
