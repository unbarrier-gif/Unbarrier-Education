01 · Context

Project context & principles

Unbarrier is a values-driven practice — consultancy, personal brand, and emerging movement built around real inclusion, belonging, and neurodivergent-first design. Founder: Nici Foote. Audience: neurodivergent adults, educators, families, and the organisations that serve them.

Non-negotiable principles

  1. Accessibility is structural, not cosmetic. WCAG 2.2 AA is the floor, not the goal. See §05.
  2. Calm over density. Reduced motion respected globally. No popups, no nags, no dark patterns.
  3. Plain language. Copy reads like a human wrote it. No corporate voice, no AI-ese.
  4. Privacy-first. No cookies for analytics. No third-party trackers. No consent theatre.
  5. Performance as access. Slow sites exclude people on cheap devices / bad connections. Lighthouse ≥95 across the board.

05 · Accessibility

WCAG 2.2 AA baseline Phase 1

The statement on /legal/accessibility is the claim. This section is how we back up every promise in it. No overlay widgets — structural only.

Global CSS rules (add to design-system root)

/* Respect reduced motion */
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: 0.01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: 0.01ms !important;
    scroll-behavior: auto !important;
  }
}

/* Visible focus always */
*:focus-visible {
  outline: 2px solid var(--spring-green);
  outline-offset: 2px;
  border-radius: 2px;
}

/* Skip link pattern */
.skip-link {
  position: absolute; top: -40px; left: 8px;
  background: var(--spring-green); color: var(--amethyst);
  padding: 8px 14px; border-radius: 6px;
  font-family: "Outfit"; font-weight: 700;
  transition: top 0.15s;
}
.skip-link:focus { top: 8px; }

Per-page requirements

  • Skip link as first focusable element, points to #main
  • Landmark structure: <header> / <nav> / <main id="main"> / <footer>
  • Exactly one <h1> per page. Heading levels don't skip.
  • All interactive elements keyboard-reachable, Enter/Space activatable
  • Every form input has a visible <label>. Errors announced via aria-live="polite".
  • Images: meaningful content = descriptive alt; decorative = alt="" aria-hidden="true"

Contrast audit — known fix

Issue: --text-faint: rgba(240, 235, 229, 0.32) fails AA on amethyst (measured 3.4:1, needs 4.5:1). Fix: lift alpha to 0.5 (gives 4.9:1). Apply across design-system.

CI guardrails

  1. GitHub Actions: run @axe-core/cli against every route on PR
  2. Lighthouse CI: a11y score ≥95 blocks merge
  3. Manual keyboard walkthrough checklist committed to /docs/a11y-checklist.md, reviewed per release
Statement text: use v1.1 (March 2026) verbatim. Nici approved. Port as MDX at content/legal/accessibility.mdx.

  2. /legal/cookies — minimal (Plausible is cookieless; only functional/strictly-necessary). No cookie banner needed unless/until we add third-party tracking.

Cookie strategy

No cookie banner. Plausible uses no cookies (sets no client-side identifiers). Stripe checkout uses strictly-necessary cookies only on the Stripe-hosted checkout page (not ours). Google Appointment Schedule runs in an iframe on its own domain — their cookies, their consent, their jurisdiction. We stay clean.
