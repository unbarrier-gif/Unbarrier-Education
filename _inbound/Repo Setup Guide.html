The one change to make

  1. In Vercel: Project → Settings → Domains → "Add" → enter unbarrier.me. Vercel will tell you the exact A record value to use. As of now it's 76.76.21.21, but use whatever Vercel shows you — that's the authoritative value.
  2. Also add www.unbarrier.me in the same Domains panel → choose "Redirect to unbarrier.me". This formalises the redirect at Vercel level (CNAME is already correct).
  3. Back in Bluehost → DNS / Zone Editor → find the A record for @ with value 216.150.1.1 → Edit → change "Point To" to the Vercel IP from step 1 → Save.
  4. Set TTL to 15 minutes while we're cutting over, so any mistake propagates fast. We can raise it back to 4 hours after Cardiff.
  5. Wait 5–15 min, then check at dnschecker.org for A record on unbarrier.me — should resolve to the new Vercel IP globally within an hour.
  6. Back in Vercel Domains panel: status flips from "Invalid Configuration" → "Valid Configuration" with a green tick. SSL cert auto-issues 30s after that.
