Why single app, not Turborepo

Turborepo earns its keep when you have multiple deployable surfaces (different domains, different framework versions, separate teams). We have one domain, one team-of-one, one Next.js version. A single app means: one Vercel project, one preview URL per PR, one set of env vars to manage, one mental model for routing. We can split later if we ever need to.

07 · Bluehost DNS Do today

Point unbarrier.me at Vercel.

This is the step that actually makes unbarrier.me/hello resolve. It's a 5-minute DNS edit, then 5 minutes to a few hours of propagation. Do it the day before Cardiff at the latest — do it today if you can so we have a buffer.

Steps

  1. In Vercel: Project → Settings → Domains → Add → enter unbarrier.me → Vercel will show you the exact records you need (A record for apex, CNAME for www). Leave that tab open.
  2. Also add www.unbarrier.me in the same Domains panel and choose "Redirect to unbarrier.me".
  3. Log into Bluehost → Domains → unbarrier.me → DNS / Zone Editor
  4. Update the A record for the apex (@) to Vercel's IP — currently 76.76.21.21. Confirm exact value from the Vercel Domains panel; it's authoritative.
  5. Update the CNAME for www to cname.vercel-dns.com
  6. Remove any conflicting records — old Bluehost parking pages, old A records pointing to Bluehost servers, any AAAA records that conflict
  7. Save. Bluehost typically propagates within 5 min for most users. Check at dnschecker.org for unbarrier.me A record — should resolve to 76.76.21.21 globally within an hour.
  8. Back in Vercel Domains panel: status should flip from "Invalid Configuration" to "Valid Configuration" with a green tick. SSL cert auto-provisions in 30s after that.

Email — don't break it

Critical: if Google Workspace MX records currently live in Bluehost DNS, do not touch them. Only change A records and the www CNAME. The MX records (typically aspmx.l.google.com, alt1.aspmx.l.google.com etc.) keep hello@unbarrier.me working and must stay exactly as they are.

Backup before you change anything

Screenshot the entire Bluehost DNS zone before editing. If something goes wrong (email stops, site goes white) you have a one-glance restore reference. Send the screenshot to me on WhatsApp.
